# 사진 보관 정책 (설계 합의, 삭제 기능 미구현)

## 배경

글은 지난 소식으로 유지하되 원본 사진 용량을 줄이고, 향후 이전 사진 불러오기를 지원한다.

- 글·행사 날짜·책방 정보는 유지한다.
- 원본은 발행 월 기준 최근 3개월 보관한다. 예: 9월에는 7~9월.
- 작은 미리보기는 우선 유지하며 실제 사용량에 따라 정책을 재검토한다.
- 최근 소식에서 재사용하는 원본은 최초 업로드 날짜가 오래돼도 삭제 대상에서 제외한다.
- 초기에는 삭제 예정 목록 → 원본 ZIP 백업 다운로드 → 관리자 확인 후 정리한다.
- 원본이 없으면 불러오기 화면에 미리보기만 남아 있으며 고화질 재첨부가 필요하다고 표시한다.
- 기존 사진에 자동 소급 삭제하지 않는다. 파일 연결 참조 검사와 정확한 삭제 대상 확인을 구현한 후 별도로 승인받는다.

## 접근 보호와 별개인 경계

스테이징 Worker의 입장 암호는 Supabase 공개 미리보기 URL을 보호하지 않는다. 테스트 이미지의 공개 범위는 저장소 정책에서 별도로 검증한다. 원본은 비공개 원칙을 유지한다.

게시판에 별도로 업로드한 사진은 이 저장소 원본 삭제와 무관하다. 반면 이 서비스의 URL을 직접 참조한 외부 게시물은 삭제 시 깨질 수 있어 정리 전에 확인해야 한다.

- 달 경계/재사용/중복 참조/백업 실패/삭제 실패 TC
