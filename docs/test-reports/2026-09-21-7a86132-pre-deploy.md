## 실패·차단 상세

### TC-SEC-002 — 개발 도구 포함 전체 의존성 audit

- 상태: `FAIL`
- 영향: 현재 production dependency는 0건이지만 로컬 개발·빌드 도구 경로에 high 권고가 남아 있다.
- 재현 단계: clean install 후 `npm audit --audit-level=high`
- 기대 결과: 안전한 minor·patch 범위 적용 뒤 기존 기록보다 악화되지 않음
- 실제 결과: 10건(moderate 4, high 6). `image-size`는 vinext 안정 버전 경로, `sharp`는 miniflare·Cloudflare 도구 경로에서 탐지됨
- 로그·증거: 이 보고서의 실행 명령 표와 GitHub CI 결과
- 우회 방법: `npm audit fix --force` 사용 금지. 운영 bundle audit 0을 배포 gate로 유지
- 후속 작업: 이슈 #66의 vinext 후보와 Cloudflare 도구 업데이트를 독립 검증

### Supabase 통합·데이터 기반 브라우저 시나리오

- 상태: `BLOCKED`
- 영향: 저장·사진·권한·동시 편집·완료 후 HTML의 실제 DB/Storage 왕복을 이번 로컬 실행에서 증명하지 못함
- 재현 단계: 로컬 환경 파일의 Supabase project ref 분류
- 기대 결과: Staging 전용 project ref와 Secret Key로만 테스트 데이터 생성·정리
- 실제 결과: 로컬 파일이 Production을 가리켜 실행 전에 중단
- 로그·증거: `npm run test:integration` 3건 SKIPPED, 로컬 `/api/workspace` 503 안전 실패
- 우회 방법: 없음. Production에 테스트 데이터를 만들지 않음
- 후속 작업: `.env.staging.local`을 Git에 포함하지 않고 준비한 뒤 정확한 Staging ref guard를 통과시키고 3/3·브라우저 UAT를 실행
