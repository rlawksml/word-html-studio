## 실행 중 확인한 환경 이슈

- 첫 기준선 실행은 worktree에 `node_modules`가 없어 `vinext: command not found`로 시작하지 못했다. 운영 코드 문제가 아니며 기존 의존성 디렉터리를 읽도록 연결했다.
- 샌드박스가 공유 Vite 임시 캐시 쓰기를 막아 첫 재실행이 `EPERM`으로 중단됐다. 같은 명령을 캐시 접근 권한과 함께 실행해 47/47 PASS를 확인했다.
- 로컬 vinext 화면은 HTTP 200, 유효한 문서 제목, 본문 렌더링, 오류 overlay·console 오류 0건을 확인했다. 다만 Cloudflare 개발 Worker가 쉘에서 읽은 Supabase 값을 런타임 binding으로 전달하지 않아 Workspace API가 503이었다. 상태 변경은 없었으며 실제 날짜 상호작용은 환경변수가 연결된 owner-private Staging 배포 후 수행한다.
