## 완료된 결함 검증

### #73 자동저장 반복

- 서버 응답 전체와 로컬 상태가 서로 다른 fingerprint로 남아 성공한 PUT이 반복되는 문제를 수정했다.
- 집중 회귀 13/13, 전체 회귀 77/77, lint와 Staging 통합 3/3을 통과했다.

- 이슈 #73을 검증 결과와 함께 닫았다.

### #72 메인 이동 후 작업자 세션 소실

- 로고 메인 이동과 로그아웃이 같은 세션 삭제 함수를 사용하던 원인을 분리했다.
- 로고 이동은 달력·presence만 초기화하고 세션은 유지하며, 로그아웃만 서버와 탭 세션을 삭제한다.
- 집중 회귀 15/15, 전체 회귀 77/77, lint와 Staging 통합 3/3을 통과했다.
- 실제 입력자 흐름에서 새로고침 유지 → 로고 메인 이동 → 현재 월 초기화 → 같은 역할 버튼 → 암호 모달 없는 복귀를 확인했다. Worker에는 세션 DELETE가 없고 세션·workspace GET은 200이었다.
- 이슈 #72를 검증 결과와 함께 닫았다.

## 2026-09-21 추가 수동 검증

- 입력자 세션 유지 상태에서 2026년 6월 UAT 책방에 재진입하고 완료 자료 5건·사진 1장을 확인했다.
- 프로젝트의 공개 비개인 PNG를 두 번째 사진으로 업로드했다. 파일 선택기는 다중 업로드를 지원했고 화면에 사진 2장이 표시됐다.
- 두 번째 사진의 `앞으로 이동` 버튼으로 순서를 바꾼 뒤 자동 저장 시각이 표시됐고, 임시 저장 후 목록 재진입에서도 `og-bookstore-news.png → UAT 테스트 이미지` 순서가 유지됐다.
- 드래그 손잡이는 자동화 포인터 드래그로 실제 순서 변경을 확정하지 못했다. 접근 가능한 방향 버튼 순서 변경은 PASS다.
- 입력 마무리 뒤 상태가 `입력 완료`, 진행률이 `1/9곳`, 사진이 `2장`으로 복구됐다.
- 방문자 2026년 6월 화면에서 `1개 책방·5개 소식`, 상세 사진 2장을 확인했다.
- 390×844 모바일 상세의 문서 폭과 viewport 폭이 모두 390px였고, 상세 모달이 열렸을 때 `body`와 `html` overflow가 모두 `hidden`이었다.
- HTML 편집 화면의 개별 미리보기에 5개 제목과 사진 2장이 표시됐다. 코드 보기에는 5개 제목과 사진 배치 주석 2개가 포함됐다.
- 자동화 브라우저의 clipboard bridge 오류와 blob ZIP download 이벤트 미관찰은 앱 콘솔 오류와 분리해 기록한다. 실제 ZIP 파일은 아직 회수하지 못했다.
- 별도 Chrome 연결이 두 번 응답하지 않아 실제 서로 다른 브라우저 2개 동시 편집은 실행하지 못했다.
- 앱 화면에서 업로드·저장·미리보기 중 400·401·409·413·500 또는 `InvalidKey` 오류는 관찰되지 않았다.
- 삭제 직전 사진 순서를 다시 확인해 `og-bookstore-news.png`만 선택했고, 화면에는 기존 `UAT 테스트 이미지`만 남았다.
- 삭제 후 `자동 저장됨` 시각을 확인하고 임시 저장 후 목록으로 이동했다. 목록은 소식 5건·사진 1장·작성 중을 표시했다.
- 재진입 후 소식 5건의 제목이 모두 유지되고 사진은 기존 `UAT 테스트 이미지` 1장만 남았다. 입력 마무리 뒤 진행률 `1/9곳`과 `입력 완료` 상태를 복구했다.
- 방문자 2026년 6월 상세도 기존 `UAT 테스트 이미지` 1장만 표시했다. 새로 추가했던 OG 사진의 DB 참조·입력자·방문자 노출 제거는 PASS이며, 실제 Storage 객체 부재는 대시보드에서 직접 확인하지 않았다.
