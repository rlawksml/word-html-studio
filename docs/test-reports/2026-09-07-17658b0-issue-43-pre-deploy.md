## 구현 확인

1. 개별 날짜와 `시작일·종료일` 기간 입력을 분리하고 `기간 적용` 전에는 Submission 값을 바꾸지 않는다.
2. 기간은 기존 `submissions.news` JSONB에 넣지 않고 `news_schedule_ranges`에 저장한다.
3. `save_submission_with_schedule_ranges`가 본문과 기간을 한 트랜잭션으로 저장한다.
4. 기간 제거는 물리 삭제하지 않고 `is_active=false`로 남긴다.
5. 기간을 보내지 않는 v1.0.1 형태 요청은 기존 활성 기간을 보존한다.
6. 방문자 달력은 발행 월과 관계없이 실제 날짜 또는 기간이 겹치는 달에 소식을 표시한다.
7. 방문자 상세·입력자 미리보기·개별 HTML은 같은 기간 표시 함수를 사용한다.
