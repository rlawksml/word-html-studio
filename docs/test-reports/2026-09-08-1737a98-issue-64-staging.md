## 원인과 수정

#62에서 운영 번들 취약점은 0건으로 해소했지만, 개발·빌드 도구까지 포함한 전체 audit에는 19건이 남았다. 이 중 직접 사용하는 `@cloudflare/vite-plugin` 1.37.1, Wrangler 4.92.0, Vite 8.0.13은 현재 주 버전을 유지하면서 서로 호환되는 수정 버전으로 업데이트할 수 있었다.

Cloudflare Vite plugin 1.54.5가 요구하는 Wrangler 4.129.1과 Vite 8.2.2를 함께 고정했다. 그 다음 `npm audit fix`를 `--force` 없이 적용해 Babel, Browserslist, `brace-expansion`, `fast-uri`, `fflate`, `js-yaml` 등 lockfile 안에서 안전하게 해결 가능한 간접 의존성만 갱신했다.

Vite 8.2.2 첫 빌드에서 향후 native config loader와 맞지 않는 JSON import와 확장자 없는 TypeScript import 경고 2건을 발견했다. JSON import attribute와 `.ts` 확장자를 명시한 뒤 동일 build에서 해당 경고가 0건인 것을 확인했다.
