## 브라우저 확인

- 기존 작성 중 소식을 읽기 전용으로 열어 `임시 저장 후 이동`, `계속 작성`, `저장하지 않고 이동` 세 버튼을 확인했다.
- `계속 작성`은 모달만 닫고 편집 화면을 유지했다.
- `저장하지 않고 이동`은 서버 쓰기 없이 책방 목록으로 이동했다.
- 모바일에서는 작업 버튼이 한 열 310px로 표시됐다.
- 콘솔 error·warning은 0건이었다.
