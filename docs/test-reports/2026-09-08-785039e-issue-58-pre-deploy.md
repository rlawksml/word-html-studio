## 원인과 수정

`verify`와 `supabase-integration`이 `actions/checkout@v4`, `actions/setup-node@v4`를 사용해 GitHub의 Node.js 20 지원 종료 경고가 발생했다. GitHub 공식 최신 릴리스인 [`actions/checkout@v7`](https://github.com/actions/checkout/releases/latest)과 [`actions/setup-node@v7`](https://github.com/actions/setup-node/releases/latest)로 두 job을 함께 갱신했다. 애플리케이션 테스트 Node 22, npm cache, 전체 Git 이력과 Staging Environment 설정은 바꾸지 않았다.
